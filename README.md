# Expense Buddy — Quản lý Thu Chi Gia đình

Ứng dụng quản lý tài chính & chi tiêu gia đình hiện đại bằng tiếng Việt:
- Next.js 16 + React 19 + Supabase Postgres & Auth.
- Tự động gửi thông báo chi tiêu nhóm qua Telegram Bot JAVIS (`@Javisreport_bot`).
- Trợ lý tài chính thông minh tích hợp Google Gemini 2.5 Flash, hỗ trợ tạo giao dịch qua ngôn ngữ tự nhiên (NLP).
- Quản lý danh mục & thành viên gia đình tùy biến linh hoạt.

👉 Xem chi tiết source code, hướng dẫn cài đặt và tài liệu kỹ thuật tại thư mục [expense-buddy-app](./expense-buddy-app).
